# Context

Context is a Rust desktop assistant for Windows, macOS and Linux. Press a shortcut in any app. Context reads the screen, works out what you're doing, and shows a short answer in the corner without taking you out of your work.

It uses your ChatGPT plan to analyze one screen capture on demand. It can also check connected [sources](docs/sources.md), which are MCP servers for things like your calendar or team docs. Results are kept in an encrypted local history. See [Development](docs/development.md) to run it and [the project wiki](docs/README.md) for the design and roadmap.
